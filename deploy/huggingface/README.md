# GMAT Focus Trainer — demo

Adaptive study platform for the GMAT Focus Edition: 5 difficulty levels anchored to real score bands, per-topic
promotion/demotion, weak-topic diagnosis, spaced repetition and an IRT-based CAT mock exam.

This demo runs on a small bank of **original sample questions**. The database is shared by all visitors and is reset
whenever the Space restarts.

Source code: https://github.com/LudmilaGuedes/gmat-focus-trainer
