# Capturas de tela

Capture com o app rodando o **banco de exemplo** (`GMAT_CONTENT_DIR=sample_bank`) num banco novo, para não expor
seu histórico pessoal. Largura de janela sugerida: 1280 px. Salve como PNG com estes nomes:

| Arquivo | Tela | Como chegar |
|---|---|---|
| `01-hoje.png` | Plano diário | Defina data da prova e meta em ⚙ Configurações, faça 1 lição e abra **Hoje** |
| `02-pratica.png` | Questão de prática (de preferência Data Insights com tabela ou gráfico) | Trilha → um assunto → Praticar |
| `03-feedback.png` | Feedback de um erro com explicação e "por que errou" | Responda errado uma questão |
| `04-simulado.png` | Questão de simulado com cronômetro (Reading Comprehension mostra o layout dividido) | Simulado → seção Verbal |
| `05-resultado.png` | Resultado do simulado com nota estimada por seção | Termine uma seção do simulado |
| `06-progresso.png` | Progresso: níveis por assunto e tópicos fracos | Depois de algumas sessões de prática |

Opcional: um GIF de 15-20 s (`demo.gif`) mostrando responder uma questão → feedback → nível subindo.
